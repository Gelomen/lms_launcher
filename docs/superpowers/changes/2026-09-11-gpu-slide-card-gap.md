# 变更：GPU 卡片切卡动画相邻卡片固定间距

日期：2026-09-11
状态：已实施（npm test 353 全绿；npm run build 通过；待用户真机目检动画）
关联规格：docs/superpowers/specs/2026-09-09-gpu-card-design.md §5.2

## 背景与用户诉求

用户报告（附截图）：GPU 信息卡片切换显卡动画过程中，相邻的显卡信息数据
紧贴在一起（屏外停靠位 ±100% 恰好等于舞台宽度，两张卡的边缘零间距），
切换动画停下后离场层被 visibility:hidden 突然移除，视觉上出现
"紧贴→突然消失"的跳变，很不舒服。

用户指定效果：相邻显卡信息之间保持固定距离 = 信息内容边缘到卡片边缘距离的
两倍；切换时显卡信息以固定距离滑入/滑出。

## 根因

- .gpu-layer 是 left:0; right:0 的绝对定位层，舞台宽 = 内容区宽；
  .gpu-pos-l/r 的 translateX(±100%) 停靠位恰好让屏外层与舞台边缘齐平，
  两张相邻卡边缘间距为 0。
- 内容相对卡片的边缘距离 = .gpu-body--nav 的 32px 按钮让位 + .card 的
  --card-pad 16px 内边距 = 48px；而屏外停靠位没有任何额外留白。
- settle 时离场层 on=false → visibility:hidden，紧贴着舞台边缘的层瞬间消失，
  形成跳变感。

## 方案

屏外停靠位从 ±100% 改为 ±(100% + 2 × (32px + var(--card-pad)))：
相邻卡片固定间距 = 96px（= 2 × 48px，即内容边缘到卡片边缘距离的两倍，用户指定）。
- 滑入/滑出全程两张卡保持 96px 固定间隔；
- settle 隐藏离场层时，层已停在距舞台边缘 96px 处，消失不再贴边，无跳变感；
- 裁切仍由 .card--gpu（overflow:hidden）承担，停靠位远在卡外，不引入新的溢出。

改动量：src/style.css 2 行（.gpu-pos-l/.gpu-pos-r 的 transform）+ 注释；
src/modules/GpuModule.vue 1 行注释同步；JS 逻辑零改动（槽位不变量不变，
posClass 映射不变，单测断言的类名切换全部保持）。

## 验收

- [x] npm test 通过（353；GpuModule 11 全绿——动画断言只锁类名切换，不受停靠位位移影响）
- [x] npm run build 通过
- [ ] 用户真机 npm run dev 目检：切卡动画相邻卡固定间隔滑入/滑出，动画结束无突然消失跳变

## 不做的事

- 不改动画结构（两层滑动、槽位不变量、settle 时序均维持 spec 定稿）
- 不动裁切容器（.card--gpu 维持 2026-09-10 定稿）
- 间距常量未抽 CSS 变量：32px 按钮让位与 --card-pad 均已有既定来源，
  单处使用，直接内联 calc 表达式 + 注释说明推导，避免变量扩散
