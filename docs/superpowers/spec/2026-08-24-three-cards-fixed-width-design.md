# 规格 —— 三卡片固定宽度（当前默认的 2/3）

## 1. 需求

用户要求将「llama.cpp 安装目录」「启动控制」「启动参数模板」三个卡片（当前布局：左列 stack 两张卡 + 右列模板卡）的宽度设为**绝对固定像素**，取值 = 默认窗口下当前默认列宽的 **2/3**。窗口放大时卡片不跟随变宽。

## 2. 尺寸推导（默认窗口 980×720）

- 内容宽 = 980 − 2·12（.layout padding）= **956px**
- 当前两列 `minmax(0, 1fr) minmax(0, 1.25fr)` + gap 12：左列 ≈ 424，右列 ≈ 520
- 默认列宽的 2/3：**左列 ≈ 280px，右列 ≈ 350px**

## 3. 改动（仅 src/style.css .grid 一行）

```css
.grid {
  /* 三卡片绝对固定宽度 = 默认列宽 × 2/3；靠左排布，右侧留白 */
  grid-template-columns: 280px 350px;
}
```

- `display: grid` / `gap: var(--card-gap)` 保持不变。
- `.stack` / 各 `.card` 不需要改动——grid item 宽度即列宽。
- 窗口 min-width 760（main.ts 已设）时：内容宽 ≥ 736，两卡占 280+12+350=642 < 736，无溢出风险；无需新增媒体查询（YAGNI）。
- 卡片高度、模板列表固定高度（.template-list 192px）、日志区布局均不受影响。

## 4. 不变项 / 边界

- 仅动 `.grid` 的 `grid-template-columns` 一行；其余样式零改动。
- 无 JS/Vue 组件改动 → 无需新增测试（项目 CSS 无单测基建）。
- 验收：刷新 GUI 后，三卡片宽度 ≈ 原值的 2/3、靠左排布；拉宽窗口卡片宽度不变。

## 5. 决策记录

- 用户已选「绝对固定像素」（窗口变化时保持恒定），而非相对比例 67%。
- 采用靠左排布（非居中），与现有布局方向一致。
