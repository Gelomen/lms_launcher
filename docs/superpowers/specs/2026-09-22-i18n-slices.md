- **目标**：i18n 基础设施（词典 / `t()` / 语言权威 / 持久化 / 测试固定 zh）+ 首批界面（设置弹窗、托盘菜单）。

- **验收**：设计总纲 §6.4（中英即时切换、托盘同语言、重启保持、词典 key 一致、中文零回归）。

- **人工验收微调**（2026-09-22，人工验收反馈 4 项，HEAD 05e6366）：语言行标签恒定 `Language` 不译（锚点，词典删 `settings.language`）/ `settings.proxy.err.partial` 文案双向对称（地址与端口须同时填写）/ 校验报错存 key 随语言即时重译（`validateError`+`ioError` 双 ref，IO 报错保持非译透传）/ 报错行下移代理输入行（`proxy-row`）下方、保存行上方，scoped `margin-top: 8px`（「中文布局冻结」对该位置解除，用户指定）。
