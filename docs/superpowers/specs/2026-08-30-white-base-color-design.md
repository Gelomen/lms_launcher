# 页面底色改为白色设计

日期：2026-08-30
状态：已批准（最小改动：仅改 --bg）

## 1. 需求

把应用底色从浅灰（#F6F7F8）改为白色（#FFFFFF）。

底色由 CSS 变量 `--bg` 定义（src/style.css 第 4 行），被 `body` 与自绘标题栏 `.winbar` 共用，
因此该变量即“页面底色”的单一来源。

## 2. 方案（最小改动）

只改 `--bg` 一处：

``css
--bg: #F6F7F8;  /* 页面底色 浅灰 */
→
--bg: #FFFFFF;  /* 页面底色 白色 */
``

- `body { background: var(--bg) }` 与 `.winbar { background: var(--bg) }` 自动跟随，
  页面底色与标题栏同步变白。
- 白色卡片 `--card`（#FFFFFF）与底色同色后，卡片仍靠 1px 边框（`--border: #E2E5E9`）+
  极浅阴影 `box-shadow` 维持层次，无需额外改动。

## 3. 非目标

- 不改其余保留 `#F6F7F8` 的**交互态**颜色（按钮 hover、未激活日志页签、下拉选项 hover、
  图标按钮 hover）——它们是控件悬停底色，不是页面底色，在白底上对比反而更清晰，保持不动。
- 不新增主题切换 / 深色模式。
- 不改持久层与 IPC。

与本次 CSS 改动无关。
